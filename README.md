# Spoken Polski

**Polski lektor do [Spoken](https://github.com/rusty-key/spoken-wow) w WoW Forever.**
Polish voiceover for Spoken in WoW Forever: quest dialogue read aloud in Polish, each character type with its own voice
(orcs, trolls, tauren, dwarves, gnomes, elves and more).

## Install

Spoken supports Polish (`plPL`) since version 3.8.3.

1. Install **Spoken** (CurseForge) and **WoWPoPolskuForever**.
2. Install the pack from the Community page of the **Spoken Manager**, or extract `SpokenCommunity_polski-<version>.zip`
   from the [latest release](https://github.com/zaxcer/spoken-polish/releases) into
   `World of Warcraft\_forever_\Interface\AddOns`.
3. Restart the game. In Spoken's settings (`/sp`), main page, section Language: **Voice Language: Polski**.

## How it is made

- **Voices:** designed from scratch with ElevenLabs Voice Design; no voice is cloned from a real person. Lines are
  generated with ElevenLabs v4 Turbo.
- A recording cannot know the player's name, class or race: a standalone address ("Wojowniku!", "Zax,") is left out,
  elsewhere the player is "wędrowiec / wędrowczyni", the race "członek / członkini Hordy" (or Przymierza).
- A few creatures are voiced by processing a deep voice (Mangletooth the quillboar), so the beast lasts to the last word.
- Classic story only, no game files, nothing reposted from Spoken's official packs.

# Spoken Polski

Polish voiceover for [Spoken](https://github.com/rusty-key/spoken-wow) in WoW Forever: quest dialogue read aloud in Polish,
each character type with its own voice (orcs, trolls, tauren, goblins...).

**Status:** Durotar, 499 recordings (quest accept, progress and completion; male and female variants where the Polish
text depends on the player's sex). Gossip and the NPC chat after quests are not voiced yet.

## Install

Spoken has no Polish language yet. Until it does:

1. Install Spoken from CurseForge.
2. Extract `SpokenCommunity_polski-durotar-<version>-itIT.zip` into `World of Warcraft\_forever_\Interface\AddOns`.
3. Restart the game. In Spoken's settings (`/sp`), main page, section Language: **Voice Language: Italiano**.
